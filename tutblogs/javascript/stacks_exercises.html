Scenario-Based Practical Questions

(Easy) You are building a calculator app. Write a mental check or algorithm step to verify if simple mathematical parentheses in a string expression like ((3 + 5) * 2) are structurally valid and closed.

(Easy) Imagine you are designing a back button mechanism for a multi-page checkout flow wizard. Why would a stack be chosen here over a standard queue structure?

(Medium) A system engineer asks you to implement a stack but states you are strictly forbidden from using arrays or linked lists. You only have access to two standard FIFO Queue structures. How can you manipulate them to simulate a stack?

(Medium) You are analyzing code metrics. Design a method using a stack that reads a string block of JavaScript code and flags an error if a closing curly brace } doesn't have a matching opening brace {.

(Medium) You are optimizing an image processing pipeline. A feature requires reversing the exact sequential order of bytes in a pixel array chunk. Explain how a stack achieves this sequence reversal natively.

(Medium) You are implementing a customized stack where a client needs to know what the current minimum value inside the stack is at any exact microsecond. How can you design this so retrieving the minimum element still takes O(1) constant time? (Hint: Can you use a secondary tracking stack?).

(Hard) Think about software like Adobe Illustrator. A user makes changes to a canvas, then hits undo 5 times, then makes a completely new brushstroke. What happens to those 5 undone history states saved on your application's internal redo stack?

(Hard) In a text processing layout engine, you are tasked to evaluate a reverse polish notation (RPN) mathematical format string (e.g., ["2", "1", "+", "3", "*"] which translates to (2 + 1) * 3). Detail step-by-step how a stack reads these tokens and processes numbers versus operator symbols.

(Hard) Suppose you have a stack with numbers arranged randomly. Using only stack primitive operations (push, pop, peek, isEmpty), explain the high-level logic required to sort the stack so the smallest items end up on top. (You may use an auxiliary temporary stack).

(Hard/Interview Classic) Explain how a monolithic nested web scaper crawls a page's HTML structure looking for broken links. When it deep-dives into nested tags <div><span><a></a></span></div>, how does the underlying engine use an explicit or implicit stack tracking system to avoid getting lost?
