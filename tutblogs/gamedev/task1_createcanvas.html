TASK 1 - Create a Canvas

Published on: 2026-08-14 | Tags: #gamedev #canvas

See the Pen The First Pixel Demo by Ronica Singh (@ladyinblack) on CodePen.

Finding the Canvas

const canvas = document.getElementById("gameCanvas");

This line can be described as "Find the HTML element whose ID is gameCanvas, and store a reference to it in the variable canvas.

Getting the drawing context

const ctx = canvas.getContext("2d");

canvas is the drawing surface.

ctx is effectively our 2D drawing toolbox.

And ctx is a very common convention for "context", so you're like to see this everywhere in Canvas code.

Choosing the colour

ctx.fillStyle = "red";

This doesn't actually draw anything, but tells us "The next filled shapes I draw should use red."

Drawing the rectangle

ctx.fillRect(
    canvas.width / 2 - 100,
    canvas.height / 2 - 100,
    100,
    100
);

You may have noticed something wrong with this code. It was done deliberately. Can you identify what is wrong with this code?

A sidenote on "centering" on the Canvas

A subtle mathematical issue in the above positioning:

canvas.width / 2 - 100
canvas.height / 2 - 100

With our current 800 × 600 Canvas, that becomes:

x = 800 / 2 - 100
  = 300

y = 600 / 2 - 100
  = 200

Therefore, we're actually drawing:

          Canvas centre
               ↓
               x
               │
        ┌──────┐
        │      │
        │      │
        └──────┘

The top-left corner of our square is at (300, 200).

Because the square is 100 × 100, its center is actually:

x = 300 + 50 = 350
y = 200 + 50 = 250

The Canvas center is:

(400, 300)

So the square is 50 pixels too far up and left.

To properly center the square:

You want to subtract half the square's dimensions, not the entire dimensions.

canvas.width / 2 - 50
canvas.height / 2 - 50

Further on in this tutorial series we'll eventually write this in terms of a varaible representing the square's size.

TASK 1.1 - Exploring the Canvas Coordinate System

Your challenge:

Draw four 100 × 100 squares, one near each corner of the Canvas, with a different colour for each square.

Your constraints

For this exercise:

  • Keep the Canvas at 800 × 600.
  • Keep every square 100 × 100.
  • Use four different colours.
  • Don't use loops yet.
  • Don't create functions yet.
  • Just manually draw the four squares.

Why no loops?

Because right now, you should get comfortable thinking in Canvas coordinates before you get introduced to abstractions.
