Devlog #1 - The First Pixel

Published on: 2026-08-14 | Tags: #gamedev #canvas

Chronicles of JS13KGames 2026 game jam

Development of Chromatic Balance: Rainbow Resonance has officially begun.

I started by creating an HTML5 Canvas and accessing its 2D rendering context through JavaScript. My first objective was deliberately simple: draw a single red square.

I learned that the Canvas coordinate system begins at (0, 0) in the top-left corner and that fillRect() uses the coordinates of an object's top-left corner rathr than its center.

This may seem like a tiny first step, but this square represents the foundation of the entire game. Eventually, the Canvas will contain the colour board, musical interface, unicorn, animations and visual feedback.

First milestone: complete.
One Canvas. One square. One game beginning.

TASK 1: Create the Canvas

1. Create index.html containing:

  • the normal HTML document structure
  • a <title>
  • a <canvas>
  • the canvas should have an id of gameCanvas
  • make it 800 × 600

2. Create style.css and add the following:

body {
	margin: 0;
	background: #111;
}

canvas {
	border: 1px solid #999;
}

3. Create game.js, and figure out how to:

  • Retrieve gameCanvas.
  • Retrieve its 2D context.
  • Set a fill color.
  • Draw a rectangle.

Review Task 1 once completed.
